# WeChat Profile Collector

微信头像昵称批量采集。

一个面向 Windows 的微信头像昵称批量采集工具。导入 Excel 手机号名单，通过已登录的企业微信桌面客户端批量获取微信头像和昵称，自动保存图片并将结果写入 Excel，支持断点续跑。

## 功能

- 从 Excel 读取手机号，查询对应昵称和头像。
- 每条结果立即保存，支持中断后继续运行。
- 自动跳过昵称、头像路径和头像文件均已存在的记录。
- 支持选择企业微信进程，适用于同时登录多个账号的情况。

## 快速开始

需要 Windows、Python 3.10+ 和已登录的企业微信桌面客户端。

在项目根目录打开 PowerShell，安装依赖并生成输入模板：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --init
```

在生成的 `phone_numbers.xlsx` 第一张工作表填写数据，保留前三列表头：

| phone_number | nickname | avatar_file |
| --- | --- | --- |
| 填写待查询的 11 位大陆手机号 | 留空 | 留空 |

手机号建议设为文本格式。关闭结果 Excel，打开并登录企业微信，然后运行：

```powershell
.\.venv\Scripts\python.exe main.py phone_numbers.xlsx
```

结果写入 `output/results.xlsx`，头像保存到 `output/avatars/`，表格中的图片路径相对于结果文件所在目录。输入表格不会被覆盖。每条查询后立即保存，Ctrl+C 停止。

重复运行会从已有结果继续，昵称和头像文件都存在的行会跳过；空结果或缺失头像的行会重试。**更换输入名单时请使用新的 `--output` 路径**，已有输出文件将作为续跑数据源。

```powershell
.\.venv\Scripts\python.exe main.py phone_numbers.xlsx --output output/batch2.xlsx --interval 3
# 同时登录多个企业微信时，在任务管理器中确认目标窗口进程 ID
.\.venv\Scripts\python.exe main.py phone_numbers.xlsx --pid 1234
```

以下命令均在项目根目录运行，使用安装过依赖的 Python 环境。

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `excel` | `phone_numbers.xlsx` | 输入文件，仅支持 `.xlsx`，读取第一张工作表 |
| `--output` | `output/results.xlsx` | 独立结果文件；存在时读取它继续处理 |
| `--pid` | 自动选择唯一主窗口 | 指定目标企业微信的进程 ID |
| `--interval` | `3` | 每条查询结束后的额外等待秒数，不包含界面操作耗时 |
| `--init` | 关闭 | 创建只有表头的输入模板后退出，文件已存在时不会覆盖 |
| `--help` | — | 查看帮助 |

输入表格前三列必须依次为 `phone_number`、`nickname`、`avatar_file`。空手机号和格式不符合要求的手机号会跳过；额外列和其他工作表会保留。

默认输出结构：

```text
output/
├── results.xlsx
└── avatars/
    └── <手机号>.png
```

转移采集结果时，请一起复制结果表格和 `avatars/` 目录，保持两者的相对位置。

## 流程与代码

1. 校验表头，读取待处理记录。
2. 定位企业微信主窗口，进入“通讯录 → 新朋友（或新的客户）→ 添加客户”，支持通讯录收纳在“更多”菜单中的布局，复用已有搜索窗口。
3. 搜索手机号，展开资料，复制昵称，再截取放大的头像区域。
4. 将结果逐条写入独立表格。界面匹配或窗口连接失败时停止，保留已有结果。

| 文件 | 职责 |
| --- | --- |
| `main.py` | 命令行入口、参数和错误提示 |
| `workbook.py` | Excel 校验、续跑和原子保存 |
| `wecom.py` | 窗口连接、图像匹配、昵称和头像提取 |
| `assets/` | 流程实际使用的 12 张界面模板 |
| `tests/` | 无需操作桌面的表格流程测试 |

## 界面适配与限制

已在企业微信 `5.0.12.6013` 上验证通讯录导航、单条查询、两条连续查询、昵称写入、头像保存和断点续跑。大批量采集尚未验证。

程序通过图像匹配和坐标偏移操作桌面客户端。窗口布局、显示缩放和主题变化都可能导致匹配失败；适配其他界面时，需要更新 `assets/` 中的模板，并调整 `wecom.py` 的昵称偏移和头像区域。头像采用固定区域截图，首次使用时请检查图片内容是否正确。

若企业微信提示设备环境异常或要求扫码安全验证，请先手动完成验证，恢复登录后再运行。程序不会处理或绕过账号安全验证。

采集会占用前台窗口、鼠标键盘和剪贴板，运行期间请勿操作。程序只查询资料，不发送消息或好友申请。请仅处理有权使用的数据，手机号、昵称、头像、日志和本地表格不应提交到公开仓库。

## 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 未找到企业微信主窗口 | 确认客户端已打开、已登录，且主窗口可见 |
| 存在多个企业微信窗口 | 使用 `--pid` 指定目标窗口所属进程 |
| 未匹配到界面模板 | 检查客户端布局、主题和显示缩放，必要时更新对应模板 |
| 无法复制昵称或头像区域不正确 | 检查资料弹窗布局，调整 `wecom.py` 中对应偏移 |
| 结果 Excel 保存失败或提示权限不足 | 关闭正在打开结果文件的 Excel，再用相同命令继续运行 |
| 修改输入表后，结果没有新增记录 | 续跑会读取已有输出表；更换名单请指定新的 `--output` |

## 测试

运行表格流程测试，不会启动或操作企业微信：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

覆盖输入文件保护、表头校验、逐条保存、异常停止、缺失头像重试、续跑跳过和昵称按文本保存等逻辑。
